# m-horky/uapi20-go

This package is roughly based on the official [github.com/varlink/go](https://github.com/varlink/go) library,
exposing a [noxiouz/v2](https://github.com/noxiouz/go/tree/v2) API, further extended to target
the [the UAPI.20](https://uapi-group.org/specifications/specs/varlink/) Varlink specification.

The implementation has been fully agentic, with some human oversight.

The intent is not to replace the official library, nor to produce a production
level code that could be used long-term. The aim is to provide an early view
into possible APIs a library would expose to conform to the UAPI.20
specification while being more ergonomic to use.

Correctness of the implementation is a desirable side effect.

## Documentation

Autogenerated usage documentation is published on [GitHub Pages](https://m-horky.github.io/uapi20-go/).

API reference is published on [pkg.go.dev](https://pkg.go.dev/github.com/m-horky/uapi20-go/v2/varlink).
